# Solar Launcher v0.3 pre-launch menu

Solar v0.3 introduces the first interactive mod selector shown before a supported game starts.

The menu only appears when Solar detects at least one compatible Solar or legacy SDCafiine pack for the current Title ID.

## Controls

- `UP / DOWN` — select a mod
- `A` — enable or disable the selected mod
- `L / R` — decrease or increase its priority by 10
- `Y` — reset the selected mod to the defaults from `mod.json`
- `+` — save the current selection and launch with the enabled mods
- `B` — launch the game without mods for this launch only

## Saved selections

Selections are stored per Title ID:

```text
SD:/wiiu/SolarLauncher/config/00050000XXXXXXXX.cfg
```

The saved state can override the `enabled` and `priority` defaults from `mod.json` without editing the mod itself.

## Conflict detection

Before launch, Solar scans enabled `content/` and `aoc/` directories.

When more than one enabled mod targets the same virtual path, Solar reports that path as a conflict. The mod with the highest priority still wins because its ContentRedirection layer is added last.

To keep startup bounded, the detector stops after tracking 20,000 replacement files and marks the report as truncated.

## SDCafiine packs

Legacy packs under:

```text
SD:/wiiu/sdcafiine/TITLE_ID/
```

appear in the same menu with an `SDC` marker. Multiple legacy packs are no longer forced off permanently: the user can explicitly choose which ones Solar should layer.

For now, it is still recommended not to run the standalone SDCafiine plugin at the same time as Solar, because both plugins can create ContentRedirection layers.
