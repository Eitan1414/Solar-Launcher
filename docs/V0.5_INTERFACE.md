# Solar Launcher V0.5 - Interface

V0.5 introduces the first branded Solar Launcher pre-launch interface.

## Visual identity

The interface keeps the visual identity of the Solar Launcher logo while adapting it to the Wii U OSScreen text renderer.

The sun/logo is built primarily from `0` and `1` characters, with a few ASCII characters (`/`, `\\`, `|`, `.`, `-`, `'`) used to preserve the recognizable sun silhouette and the central L/lightning shape.

The binary logo is assembled line-by-line during a short startup animation.

The rest of the UI uses:

- black background
- white monospace OSScreen text
- Solar orange pixel separators/chrome
- binary decoration such as `0101 SOLAR READY 1010`

The current OSScreen built-in font is white-only, so orange is currently used for pixel-drawn interface accents. A later GX2 renderer may allow fully coloured text and richer graphics.

## Layout

```text
       binary Solar sun           SOLAR LAUNCHER
                                  Universal Wii U modding framework
                                  Load. Combine. Expand.

---------------------------------------------------------------------
 MODS                               MOD INFORMATION

 > [ON ] Cuphead 3 Player           Name: ...
   [OFF] Another Mod                Author: ...
   [ON ] SDCafiine Pack             Version: ...
                                    Type: ...
                                    Priority: ...
                                    Conflicts: ...
                                    Payload: C:yes A:no P:yes
                                    Source: Solar / SDCafiine
---------------------------------------------------------------------
 A Toggle   X Details   L/R Priority   Y Reset
 + Save & launch mods   B Launch vanilla once
 0101 SOLAR READY 1010   Page 1/1   File conflicts: 0
```

## Controls

- D-Pad Up/Down: select a mod
- A: enable/disable selected mod
- X: switch between Mod Information and Technical Details
- L/R: decrease/increase priority by 10
- Y: restore selected mod defaults
- Plus: save selection and launch
- B: launch the game vanilla once without applying selected mods

## Technical details view

Pressing X shows:

- running Title ID
- mod folder
- Solar vs SDCafiine source
- current enabled state and priority
- default state and priority
- presence of `content/`
- presence of `aoc/`
- presence of `patches/`

## Implementation

The current renderer remains based on `OSScreen` so the menu stays lightweight and compatible with the existing V0.3/V0.4 menu architecture. `OSScreenPutFontEx` renders the binary/text interface while `OSScreenPutPixelEx` draws Solar-orange separators.

This is the first interface pass and must still be visually validated on a real Wii U TV and GamePad before it is considered final.
